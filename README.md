# 三角洲行动 3D · Delta Force 同人网页版

浏览器里的 3D 搜打撤：烽火地带 · 零号大坝。单个 HTML 文件，Three.js 已内联；哈夫币与仓库保存在浏览器本地。

**在线试玩：** https://strawberry-eat-mango.github.io/delta3d/

## 玩法
- 大厅：选择干员（红狼 / 蜂医 / 露娜 / 乌鲁鲁，各有技能），从仓库配装，在交易行用哈夫币购买武器、弹药、1–5 级护甲与头盔、背包、药品
- 行动：零号大坝（大坝、河流、湖泊）— 行政辖区、水电站、水泥厂、军营、游客中心、零号村、湖畔小屋
- 搜索抽屉柜 / 电脑机箱 / 手提箱 / 保险箱 / 武器箱等容器，物品按稀有度逐个揭示（白 / 绿 / 蓝 / 紫 / 金 / 红）
- 阿萨拉卫队巡逻据点，首领「赛伊德」坐镇行政辖区；敌方干员同样在搜刮并撤离
- 15 分钟内抵达撤离点并停留 7 秒即撤离成功，战利品自动折算哈夫币；阵亡则丢失携带物资（安全箱内物品保留）

## 键位
WASD 移动 · Shift 奔跑 · 空格 跳 · C 蹲 · Z 趴 · 左键 开火 · 右键 瞄准 · R 换弹 · B 射击模式 · 1/2 切枪
Q 干员技能 · G 手雷 · F 搜索/拾取 · 4-7 药品 · Tab 背包 · M 地图 · V 视角 · Esc 暂停

## 构建
源码在 `src/`，运行 `python3 build.py` 生成 `index.html`。
